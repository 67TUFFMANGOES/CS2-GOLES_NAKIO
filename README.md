# Electric Bill Calculator

## Description
This program calculates the electricity bill of the user.

## Version 1 - Original code without input validation
- Input: Accepts a user's name and two meter readings scores.
- Process: Calculates and displays the total cost.
- Output: Cost.
- Does not include input validation.

## Version 2 - Original code with input validation
- Input: Accepts a user's name and two meter readings scores.
- Process: Calculates and displays the total cost.
- Output: Cost.
- Does include input validation.
